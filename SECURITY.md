# Security policy

Security fixes apply to the latest commit on `main`.

Report suspected security issues privately to:

`carl-leander [dot] henneking [at] epiqglobal [dot] com`

Replace `[at]` with `@` and `[dot]` with `.`. Remove the spaces. Do not report security issues in public issues or pull requests.

Include the affected commit, the impact, and steps to reproduce the issue. Do not include credentials or confidential data.

We will review the report and coordinate a fix and disclosure with you.
